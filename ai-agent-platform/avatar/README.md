# Avatar modular

Esta pasta é o ponto de entrada dos assets da futura personagem.

Nenhum modelo definitivo é incluído nesta etapa.

A estrutura esperada separa os componentes para permitir troca independente:

- `body/`
- `face/`
- `hair/`
- `outfits/`
- `shoes/`
- `accessories/`
- `animations/`

Os assets devem entrar em formato compatível com o runtime PlayCanvas/glTF e ser registrados pelo Avatar System, sem acoplar roupas ou acessórios à lógica da agente.
